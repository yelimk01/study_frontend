# EnjoyTrip

**지역 관광정보를 찾고 여행 경험을 나누는 프론트엔드 서비스**

한국관광공사 TourAPI와 카카오 지도를 활용하여 지역·유형별 관광정보와 상세정보를 제공합니다. 회원가입과 회원 관리, 공지사항 및 공유게시판 기능을 함께 구현했습니다. HTML 페이지별로 JavaScript를 분리하고 공통 회원 기능과 데이터 저장 로직을 공유하는 구조입니다.

## 1. 기술 구성

| 구분 | 기술 및 용도 |
| --- | --- |
| 화면 | HTML5, CSS3, Bootstrap 5.3.3 |
| 동작 | Vanilla JavaScript, DOM 조작, 이벤트 처리 |
| API 통신 | Fetch API, AbortController |
| 관광정보 | 한국관광공사 TourAPI · KorService2 |
| 지도 | Kakao Maps JavaScript SDK |
| 데이터 저장 | 브라우저 localStorage |
| 비밀번호 처리 | Web Crypto API · salt 및 SHA-256 해시 |
| 실행 | VS Code Live Server 또는 Python 정적 HTTP 서버 |

별도 빌드 도구나 백엔드 서버 없이 실행하는 프론트엔드 프로젝트입니다.

## 2. 주요 기능

### 메인 화면

- 서비스 소개와 관광정보 조회 페이지 진입
- 관광지·문화시설·음식점 바로가기 및 선택한 유형을 조회 화면에 전달
- TourAPI에서 관광지 사진 후보를 가져와 무작위 여행지 사진·이름·주소 표시
- 사진 로딩 실패 시 다른 후보를 시도하고 기본 배경과 안내 문구 제공

### 관광정보 조회 · F101~F103

- 시·도와 시·군·구를 선택하여 지역별 관광정보 조회
- 관광지, 숙박, 음식점, 문화시설, 공연·행사, 여행코스, 쇼핑 유형별 필터
- 사진·유형·이름·주소를 카드 형태로 표시
- 조회 결과를 12개씩 표시하고 이전·다음 페이지 이동
- 총 결과 수와 현재 조회 범위 표시
- 시·군·구 목록 캐시 및 지역 변경 시 이전 요청 취소
- 로딩, 빈 결과, 이미지·좌표 누락, API 오류와 응답 시간 초과 안내

### 관광정보 상세 및 지도

- 상세보기 대화상자에서 사진·이름·유형·주소·연락처·소개 표시
- `detailCommon2`로 추가 상세정보를 조회하고 결과 캐시
- 상세 조회 실패 시 기본정보 유지 및 재시도 제공
- 카카오 지도에 현재 페이지의 관광지 마커 표시
- 카드의 지도 버튼이나 마커 선택 시 해당 위치와 장소명 표시
- 상세 화면에서 지도 위치로 이동
- 검색 결과가 바뀌면 기존 마커 제거 후 새 결과 반영
- 지도 로딩 실패 시에도 관광정보 목록 조회 가능

### 회원가입 · F107

- 아이디·이름·이메일·비밀번호·비밀번호 확인 입력
- 필수 입력과 이메일 형식 검사
- 아이디 형식 및 중복 검사, 이메일 중복 검사
- 비밀번호 조건과 확인값 검사
- 회원정보 저장 후 로그인 페이지 이동

| 항목 | 입력 조건 |
| --- | --- |
| 아이디 | 영문·숫자·밑줄로 4~20자, 중복 검사 시 대소문자 구분 없음 |
| 이메일 | 이메일 형식 검사, 앞뒤 공백 제거 및 소문자로 저장 |
| 비밀번호 | 영문과 숫자를 포함한 8~64자 |

### 로그인·로그아웃·비밀번호 찾기 · F108

- 아이디와 비밀번호 해시 확인 후 로그인 상태 저장
- 가입 완료 및 비밀번호 변경 안내
- 로그인 여부에 따라 공통 메뉴 변경
- 로그아웃 시 로그인 상태 삭제 후 로그인 화면 이동
- 아이디와 가입 이메일 확인 후 새 비밀번호 설정
- 비밀번호 변경 후 해당 회원의 현재 로그인 상태 해제

비밀번호 찾기는 **이메일 발송 없이 가입 정보를 확인하는 학습용 재설정 흐름**입니다.

### 회원정보 관리 · F107

- 로그인한 회원의 아이디·이름·이메일 조회
- 아이디는 읽기 전용으로 표시
- 이름·이메일 수정 및 다른 회원의 이메일과 중복 검사
- 비회원 접근 시 로그인 화면으로 이동
- 탈퇴 확인창에서 취소 또는 최종 탈퇴
- 탈퇴 시 회원정보와 로그인 상태 삭제 후 메인 화면 이동
- 탈퇴 확인창에서 Escape로 닫기 및 Tab 키 초점 순환

### 공지사항·공유게시판 · F109~F110

- 목록·상세 조회 및 제목·내용 검색
- 작성일 기준 최신 글부터 표시
- 로그인한 회원의 글 등록
- 작성자 본인의 글 수정·삭제 및 삭제 확인
- 수정된 글에 수정 여부 표시
- 공지사항과 공유게시판을 별도 저장 키로 관리
- 동일한 `community.js`를 두 화면에서 재사용

| 사용자 상태 | 제공 기능 |
| --- | --- |
| 비회원 | 목록·상세 조회, 검색 |
| 로그인한 회원 | 조회·검색·글 작성 |
| 해당 글 작성자 | 본인 글 수정·삭제 |

공지사항도 회원이 작성하는 구조이며 별도 관리자 역할은 없습니다. 탈퇴 후 게시글은 유지되고 동일 아이디로 재가입해도 이전 글의 수정 권한을 얻지 않습니다.

## 4. 데이터 구조

관광정보는 외부 API에서 조회하며 회원정보와 게시글은 localStorage에 JSON으로 저장합니다.

| 저장 키 | 저장 내용 |
| --- | --- |
| `enjoytrip.users` | 회원 객체 배열 |
| `enjoytrip.currentUser` | 로그인한 회원의 아이디 문자열 |
| `enjoytrip.notices` | 공지사항 객체 배열 |
| `enjoytrip.board` | 공유게시판 객체 배열 |

### 회원 객체

```javascript
{
  id,           // 아이디
  name,         // 이름
  email,        // 이메일
  salt,         // 회원별 임의 값
  passwordHash, // salt와 비밀번호의 SHA-256 해시
  createdAt     // 가입 시각 (ISO 문자열)
}
```

### 게시글 객체

```javascript
{
  id,              // UUID
  title,           // 제목
  content,         // 내용
  authorId,        // 작성자 아이디
  authorCreatedAt, // 작성자 가입 시각
  authorName,      // 작성 시점의 이름
  createdAt,       // 작성 시각
  updatedAt        // 수정 시 추가되는 수정 시각
}
```

수정·삭제 권한은 작성자 아이디와 가입 시각을 함께 비교합니다. 동일 브라우저의 같은 실행 주소에서는 새로고침 후 데이터가 유지됩니다. 다른 PC·브라우저·실행 주소와는 데이터가 공유되지 않습니다.

## 5. 실행 방법

### 설정 준비

프로젝트 루트에서 `js/config.example.js`를 `js/config.js`로 복사합니다. 기존 설정이 있다면 유지합니다.

```javascript
window.APP_CONFIG = {
  TOUR_API_KEY: "한국관광공사 인증키",
  KAKAO_JS_KEY: "카카오 JavaScript 키",
  SGIS_CONSUMER_KEY: "",
  SGIS_CONSUMER_SECRET: ""
};
```

- 관광정보 조회와 메인 사진에는 한국관광공사 API 키가 필요합니다.
- 지도에는 별도의 카카오 JavaScript 키가 필요합니다.
- 카카오맵 사용 설정과 실제 실행 도메인을 확인합니다.
- `localhost`와 `127.0.0.1`을 모두 사용한다면 각각 도메인을 등록합니다.
- SGIS 설정 필드는 준비되어 있지만 현재 지도 구현은 Kakao Maps를 사용합니다.
- 실제 키가 포함된 설정 파일은 커밋하지 않습니다.

### 개발 서버 실행

VS Code Live Server로 `index.html`을 열거나 다음 명령을 실행합니다.

```bash
python -m http.server 5500
```

브라우저에서 [http://localhost:5500](http://localhost:5500)에 접속합니다. Bootstrap과 외부 API를 위해 인터넷 연결이 필요하며 Web Crypto 기능을 위해 localhost 또는 HTTPS 환경에서 실행합니다.

## 6. 구현 범위

- 현재 구현: 관광정보 조회·상세·지도, 메인 사진, 회원 관리, 로그인 관리, 공지사항·공유게시판
- 미구현: 여행 계획·경로 저장, Hotplace 등록, 관광지 뉴스 크롤링, SGIS 지도, 날씨·일출·일몰·충전소 정보
- 회원·게시판은 프론트엔드 시연이며 서버 인증, 실제 이메일 본인 확인, DB 연동은 없습니다.
- localStorage의 회원·권한 정보는 사용자가 수정할 수 있습니다. 실제 서비스에는 서버 인증·인가와 비밀번호 전용 해시 처리가 필요합니다.
