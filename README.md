# EnjoyTrip

공공데이터를 활용한 지역 관광정보 조회와 회원·커뮤니티 서비스를 제공하는 프론트엔드 프로젝트입니다.

- 팀원: 김현준, 강예림
- 기술: HTML5, CSS3, Vanilla JavaScript, Bootstrap 5.3.3
- 별도 프레임워크, 빌드 도구, 백엔드 없이 실행합니다.

## 실행 방법

1. VS Code에서 프로젝트 폴더를 엽니다.
2. `js/config.example.js`를 `js/config.js`로 복사합니다.
   기존 설정 파일이 있다면 유지합니다.
3. 관광 API와 지도 사용을 위한 키를 설정합니다.
4. Live Server로 `index.html`을 실행합니다.

Python 개발 서버를 사용할 수도 있습니다.

```bash
python -m http.server 5500
```

실행 후 http://localhost:5500 에 접속합니다.

Bootstrap CDN을 위해 인터넷 연결이 필요합니다.
회원 기능의 Web Crypto 사용을 위해 localhost 또는 HTTPS로 실행합니다.
실제 API 키가 포함된 `js/config.js`는 커밋하지 않습니다.

## 관광정보 조회

- 시·도, 시·군·구, 관광 유형을 선택하여 한국관광공사 API를 조회합니다.
- 결과는 12개씩 표시하며 이전·다음 페이지로 이동합니다.
- 카카오 지도에 현재 페이지의 관광지 마커를 표시합니다.
- 좌표가 있는 결과의 '지도에서 보기'를 누르면 해당 마커로 이동합니다.
- 지도 설정에 문제가 있어도 관광정보 목록 조회는 가능합니다.
- 이미지·좌표 누락, 로딩, 빈 결과, API 오류를 안내합니다.
- 관광정보 상세 모달은 아직 구현하지 않았습니다.

### API 및 지도 설정

`js/config.js`의 `TOUR_API_KEY`, `KAKAO_JS_KEY`에 발급받은 키를 입력합니다.

카카오디벨로퍼스에서 해당 앱의 카카오맵 사용 설정을 활성화하고,
JavaScript SDK 도메인에 실제 개발 주소를 등록합니다.

- 예: `http://localhost:5500`
- `127.0.0.1`로 접속한다면 `http://127.0.0.1:5500`도 등록합니다.

데이터 및 사진 출처는 한국관광공사 TourAPI이며 지도는 Kakao Maps입니다.
관광지 페이지는 KorService2 API를 사용합니다.
SGIS는 구현하지 않았으며 수업에서 필수로 요구하는 경우 별도 연동이 필요합니다.

## 회원 관리

- 회원가입: 필수값, 아이디 형식·중복, 이메일 형식·중복, 비밀번호 확인 검사
- 로그인: 아이디·비밀번호 확인 후 로그인 상태 저장
- 로그아웃: 로그인 상태 삭제
- 공통 메뉴: 로그인 여부에 따라 회원가입·로그인·회원정보·로그아웃 표시
- 비밀번호 찾기: 아이디·가입 이메일 확인 후 새 비밀번호 설정
- 회원정보: 로그인한 회원의 정보 조회, 이름·이메일 수정
- 회원탈퇴: 확인창에서 최종 확인 후 회원정보와 로그인 상태 삭제

아이디는 수정할 수 없습니다.
아이디는 영문·숫자·밑줄로 4~20자 입력합니다.
비밀번호는 영문과 숫자를 포함하여 8~64자 입력합니다.

## 공지사항 및 공유게시판

- 비회원도 목록·상세 조회와 검색이 가능합니다.
- 로그인한 회원은 글을 작성할 수 있습니다.
- 수정·삭제는 작성자에게만 제공됩니다.
- 별도 관리자 역할은 구현하지 않았습니다.
- 탈퇴 후 작성한 게시글은 유지됩니다.
- 같은 아이디로 재가입해도 이전 글의 수정 권한을 얻지 않습니다.

## 저장 데이터

| 저장 키 | 내용 |
| --- | --- |
| `enjoytrip.users` | 회원 목록 |
| `enjoytrip.currentUser` | 로그인한 회원 아이디 |
| `enjoytrip.notices` | 공지사항 목록 |
| `enjoytrip.board` | 공유게시판 목록 |

회원 객체는 다음 필드를 사용합니다.

```javascript
{
  id,
  name,
  email,
  salt,
  passwordHash,
  createdAt
}
```

회원정보와 게시글은 브라우저 localStorage에 저장합니다.
새로고침 후에도 유지되지만 다른 PC나 브라우저와 공유되지 않습니다.

## 회원 기능의 시연 범위

회원 인증과 비밀번호 재설정은 프론트엔드 학습용 구현입니다.
실제 이메일 발송, 본인 인증, 서버 세션, DB 연동은 제공하지 않습니다.

비밀번호는 salt와 SHA-256 해시로 저장합니다.
실제 서비스에서는 서버에서 비밀번호 전용 해시와 인증·인가를 구현해야 합니다.
localStorage는 사용자가 수정할 수 있으므로 실제 접근 통제를 대신하지 않습니다.

## 확인 시나리오

### 관광정보

지역·시군구 선택 → 유형 선택 → 조회 → 페이지 이동 → 지도에서 보기

이미지·좌표 누락, 빈 결과, API 오류, 지도 설정 오류도 확인합니다.

### 회원 및 커뮤니티

회원가입 → 중복 가입 거절 → 잘못된 로그인 거절 → 로그인 →
회원정보 조회·수정 → 로그아웃 → 비회원 회원정보 접근 제한 →
비밀번호 재설정 → 이전 비밀번호 로그인 실패 → 새 비밀번호 로그인 →
게시글 등록·검색·상세·수정·삭제 → 다른 회원 수정 제한 →
탈퇴 취소·확정

새로고침 후 저장 데이터가 유지되는지도 확인합니다.

## 검증 결과

### 관광정보

관광 담당자의 검증 기록에 따르면 실제 API로 지역·시군구 목록,
서울 관광지 조회, 페이지 이동, 모바일 화면을 확인했습니다.

지도 SDK는 앱 서비스 비활성화로 403 응답을 받았습니다.
마커 표시·교체·선택 로직은 모의 SDK로 검증했습니다.
카카오맵 사용 설정을 활성화한 뒤 실제 지도 화면을 추가 확인해야 합니다.

### 회원 및 커뮤니티

JavaScript 전체 문법 검사를 통과했습니다.

Node VM의 DOM·저장소 모의 환경에서 회원가입, 중복 방지, 해시 저장,
로그인 성공·실패, 회원 수정, 비밀번호 재설정, 기존 비밀번호 거절,
세션 해제, 공지사항·게시판 CRUD, 작성 권한, 탈퇴,
비회원 접근 제한, 손상 데이터 감지를 검사했습니다.

실행 환경의 브라우저 설치 실패로 실제 브라우저의 폼 검증,
탈퇴 확인창, 반응형 화면 검증은 완료하지 못했습니다.
